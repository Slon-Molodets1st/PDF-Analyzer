# Analiz-Chatbot

Приложение для анализа pdf-документов с использованием AI (LangChain, LangGraph, Ollama)

## 🚀 Возможности

- 💬 **Чат с документом** - задавайте вопросы по содержимому PDF
- 🔍 **Извлечение сущностей** - автоматический анализ контрактов
- 🔄 **Поиск противоречий** - выявление логических и юридических противоречий
- 🤖 **Умный агент** - поиск информации в документе и интернете

## 📋 Требования

- Python 3.10+
- Ollama с моделями:
  - `llama3.2` (или другая LLM)
  - `all-minilm` (для эмбеддингов)
